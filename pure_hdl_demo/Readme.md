# Демо-проект: Распознавание цифр MNIST на ПЛИС

Полносвязная нейронная сеть для классификации рукописных цифр, реализованная аппаратно на ПЛИС. 
Проект обрабатывает видеопоток с камеры в реальном времени и выводит результат распознавания.

## Аппаратная платформа

- **ПЛИС:** Intel Cyclone V 
- **Камера:** модуль D8M_GPIO
- **Вывод видео:** VGA-монитор
- **Индикация результата:** восьмисегментный индикатор

## Принцип работы

1. Камера непрерывно захватывает изображение.
2. На VGA-монитор выводится видеопоток. **В центре кадра отображается жёлтый квадрат** — это область интереса для распознавания.
3. Поместите лист бумаги с рукописной цифрой так, чтобы цифра оказалась **внутри жёлтого квадрата**.
4. Если камера расфокусирована то нажмите **кнопку с индексом 0** на плате — это обновит фокус камеры.
5. Полносвязная нейронная сеть, аппаратно реализованная в ПЛИС, выполняет классификацию.
6. Распознанная цифра (0–9) отображается на **восьмисегментном индикаторе**.

## Важные требования для работы

- **Освещение.** Камера должна быть направлена на хорошо освещённую поверхность. Недостаточное или неравномерное освещение резко ухудшает качество распознавания.
- **Контраст.** Используйте чёрную цифру на белом фоне (без теней и посторонних объектов внутри жёлтого квадрата).
- **Положение.** Цифра должна располагаться по центру жёлтого квадрата — сеть чувствительна к сдвигам.
- **Масштаб.** Цифра не должна быть слишком маленькой или слишком большой внутри квадрата.
