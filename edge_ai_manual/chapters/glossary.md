# Глоссарий <a name="glossary"></a>

|  |  |
| :---- | :---- |
| **ASIC** <a name="asic"></a>| application-specific integrated circuit (интегральная схема специального назначения) – тип микросхем для решения строго определенной задачи; микроархитектура фиксирована и не является перепрограммируемой в отличие от ПЛИС. |
| **BatchNorm** <a name="batchnorm"></a>| batch normalization (нормализация по батчам) – техника нормализации входных данных слоёв нейронной сети путём вычитания среднего и деления на стандартное отклонение; улучшает сходимость обучения и устойчивость модели, но требует дополнительных вычислений. |
| **BRAM** <a name="bram"></a>| block random access memory (блочная оперативная память, встроенная память) – специализированные блоки быстрой встроенной памяти на FPGA, используемые для хранения данных, весов нейронных сетей и промежуточных результатов; обеспечивают быстрый доступ с минимальными задержками. |
| **CNN** <a name="cnn"></a>| convolutional neural network (свёрточная нейронная сеть) – архитектура нейронной сети, использующая операции свёртки для обработки пространственных данных, в особенности эффективная для задач компьютерного зрения и анализа изображений. |
| **CPU** <a name="cpu"></a>| central processing unit (центральный процессор) – универсальный процессор общего назначения, ответственный за управление и координацию работы всех компонентов компьютерной системы. |
| **DSP** <a name="dsp"></a>| digital signal processing (цифровая обработка сигналов) – специализированные аппаратные блоки на FPGA, оптимизированные для выполнения арифметических операций (умножение, накопление), часто используемые для реализации операций умножения-накопления (MAC) в нейронных сетях. |
| **Edge AI** <a name="edgeai"></a> | edge artificial intelligence (краевой искусственный интеллект, КИИ) – парадигма выполнения инференса нейронных сетей на краевых вычислителях, то есть устройствах, расположенных максимально приближенно к источнику обрабатываемых данных. |
| **FPGA** <a name="fpga"></a> | field programmable gate array  (программируемые логические интегральные схемы, ПЛИС) – тип микросхем для решения широкого спектра задач; ключевая особенность заключается в возможности перепрограммирования связей между логическими элементами для достижения желаемой логики работы устройства. |
| **FSM** <a name="fsm"></a>| finite state machine (конечный автомат состояний) – цифровая логика, используемая для управления последовательностью операций и потоком данных в аппаратных системах; в нейропроцессорах на FPGA координирует работу вычислительных блоков и памяти. |
| **GPU** <a name="gpu"></a>| graphics processing unit (графический процессор, графический ускоритель) – специализированный процессор, оптимизированный для параллельной обработки больших объёмов данных; широко используется для обучения и инференса нейронных сетей. |
| **HLS** <a name="hls"></a>| high-level synthesis (высокоуровневый синтез) – процесс автоматического преобразования алгоритмов, описанных на языках высокого уровня (C, C++), в синтезируемый RTL-код (Verilog/VHDL) для реализации на FPGA; позволяет ускорить разработку по сравнению с ручным написанием HDL. |
| **IoT** <a name="iot"></a>| internet of things (интернет вещей) – сетевая инфраструктура, соединяющая физические устройства (датчики, исполнительные механизмы) через интернет; Edge AI на FPGA часто используется в IoT-приложениях для локальной обработки данных. |
| **IP** <a name="ip"></a>| intellectual property core (IP-ядро) – готовый или повторно используемый аппаратный блок, который можно интегрировать в FPGA-проект как часть цифровой системы. |
| **Layer Buffer** <a name="layerbuffer"></a>| буфер слоёв – область памяти для хранения промежуточных активаций нейронной сети между этапами вычисления, особенно важная при последовательной обработке слоёв на FPGA. |
| **LiDAR** <a name="lidar"></a>| light detection and ranging (лидар, оптический радар) – телеметрическая технология, использующая лазерный луч для измерения расстояний и создания трёхмерных карт окружающей среды; применяется в системах автономной навигации и робототехнике. |
| **LSTM** <a name="lstm"></a>| long short-term memory (долгая краткосрочная память) – архитектура рекуррентной нейронной сети, способная обучаться и запоминать долгосрочные зависимости в последовательностях данных; применяется для обработки временных рядов и текста. |
| **MAC** <a name="mac"></a>| multiply-accumulate (умножение с накоплением) – основная арифметическая операция в нейронных сетях, выполняющая умножение двух операндов и добавление результата к накопленной сумме; является базовой операцией для вычисления взвешенных сумм нейронов. |
| **QAT** <a name="qat"></a>| quantization-aware training — метод обучения нейронных сетей, в котором квантизационные эффекты (низкоразрядная арифметика) моделируются во время прямого и обратного проходов; позволяет значительно уменьшить падение точности при последующей квантизации в int8/int4 и при развёртывании на аппаратуре. |
| **ReLU** <a name="relu"></a>| rectified linear unit (выпрямленная линейная функция) – функция активации нейронной сети, определяемая как f(x) = max(0, x); широко используется из-за простоты реализации на FPGA и эффективности обучения. |
| **Ring Buffer** <a name="ringbuffer"></a>| – циклический буфер памяти, организованный как кольцевая структура данных, где после достижения конца буфер возвращается к началу; используется на FPGA для эффективного хранения и обработки данных в нейронных сетях. |
| **RNN** <a name="rnn"></a>| recurrent neural network (рекуррентная нейронная сеть) – архитектура нейронной сети с циклическими соединениями, позволяющая обрабатывать последовательные данные с сохранением информации о предыдущих состояниях. |
| **RTL** <a name="rtl"></a>| register transfer level (уровень передачи регистров) – уровень абстракции для описания цифровых схем, на котором определяются передачи данных между регистрами и логическими операциями; используется при проектировании FPGA в языках VHDL и Verilog. |
| **SLAM** <a name="slam"></a>| simultaneous localization and mapping (одновременная локализация и картирование) – алгоритм для автономной навигации мобильных роботов, одновременно строящий карту окружающего пространства и определяющий позицию робота. |
| **SoC** <a name="soc"></a>| system on chip (система на кристалле) – интегральная схема, содержащая все основные компоненты вычислительной системы (процессор, память, периферия) на одном кремниевом кристалле; часто используется в FPGA архитектурах типа Xilinx Zynq или Intel Agilex. |
| **TNN** <a name="tnn"></a>| transformer neural network (трансформерная нейронная сеть) – современная архитектура глубокого обучения, основанная на механизме внимания (attention), позволяющая эффективно обрабатывать последовательности данных с параллельными вычислениями; широко используется в обработке текста, компьютерном зрении и других задачах. |
| **Timing analysis** <a name="timing"></a>| анализ временных ограничений – проверка того, что все сигнальные пути цифрового проекта укладываются в заданный период тактового сигнала и не нарушают требования setup/hold. |
| **TPU** <a name="tpu"></a>| tensor processing unit (тензорный процессор) – специализированный ускоритель для операций машинного обучения, прежде всего матричных и тензорных вычислений. |
| **Verilog** <a name="verilog"></a>| – язык описания аппаратуры, альтернативный VHDL, широко используемый для описания FPGA и ASIC; обеспечивает более компактный синтаксис и широко применяется в промышленности и открытых проектах. |
| **VHDL** <a name="vhdl"></a>| VHSIC hardware description language (язык описания аппаратуры высокой степени интеграции) – стандартный язык для описания цифровых схем и FPGA, позволяющий определить структуру и поведение электронных устройств на уровне RTL. |
| **АЦП** <a name="adc"></a>| аналого-цифровой преобразователь (analog-to-digital converter, ADC) – устройство для преобразования аналоговых сигналов в цифровой формат для обработки на микропроцессорах и FPGA. |
| **Дистилляция знаний** <a name="distillation"></a>| knowledge distillation (дистилляция знаний) – метод передачи знаний от крупной, точной нейронной сети (учитель) к меньшей, более эффективной сети (ученик) путём обучения ученика воспроизводить выходы учителя; позволяет создавать компактные модели для Edge AI. |
| **Инференс** <a name="inference"></a> | – парадигма выполнения нейронных сетей на краевых вычислителях, то есть устройствах, расположенных максимально приближенно к источнику обрабатываемых данных. |
| **Квантизация** <a name="quantization"></a>| quantization (квантование) – процесс снижения точности представления данных (переход от float32 к int8 или бинарным форматам) в целях уменьшения потребления памяти и увеличения скорости вычислений на FPGA с минимальными потерями точности модели. |
| **Прунинг** <a name="pruning"></a>| pruning (обрезка) – метод оптимизации нейронных сетей, заключающийся в удалении менее значимых синапсов (весов) и нейронов с целью снижения вычислительной сложности и потребления памяти; может быть структурным (удаление слоёв/фильтров) или неструктурным (удаление отдельных весов). |
| **ЦАП** <a name="dac"></a>| цифро-аналоговый преобразователь (digital-to-analog converter, DAC) – устройство для преобразования цифровых сигналов в аналоговую форму для управления аналоговыми системами и элементами. |
