# Руководство по реализации Edge AI на FPGA
<div style="text-align: justify">

Этот репозиторий посвящён построению и внедрению решений краевого искусственного интеллекта (КИИ/Edge AI) на программируемых логических интегральных схемах (ПЛИС/FPGA).

Информация об имплементации Edge AI на FPGA представлена в множественных разрозненных источниках. Мы собрали ее в одном месте и изложили как теоретические аспекты, так и практические примеры полной реализации.

### Для кого это руководство?

- для инженеров и разработчиков, создающих локализованные, энергоэффективные и детерминированные решения на FPGA;
- для исследователей, изучающих интеграцию нейросетей на краевых устройствах;
- для студентов и специалистов, желающих увидеть полные примеры реализации выполнения нейронных сетей на FPGA.
